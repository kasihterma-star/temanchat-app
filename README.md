# TemanChat V7.3 — Pengingat Instal PWA

Basis: TemanChat V7.2. Semua fitur yang sudah ada dipertahankan.

Pengingat instal muncul hanya ketika chat dibuka dari browser biasa dan pengguna telah login; tidak ditampilkan saat berjalan dalam mode aplikasi standalone. Tombol × menunda selama 7 hari, tidak memaksa instal. iOS diberi instruksi manual, Android/desktop menggunakan prompt browser bila tersedia.

**Batasan:** tab browser tidak selalu dapat mendeteksi instalasi PWA yang terjadi secara terpisah. Karena itu, jika pengguna membuka situs dari tab biasa setelah instalasi, pengingat mungkin tetap muncul pada browser tertentu. Buka dari ikon aplikasi untuk menyembunyikannya.

Lihat PANDUAN-V7.3.txt untuk pemasangan.
